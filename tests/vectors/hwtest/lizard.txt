# lizard.txt: lizard mode's reports, in send order, through the library's lizard.c and the runner's
# model (docs/testing.md). START = a fresh opensc2_lizard_reset(), the rule word 0 (none of lizard
# mode's processing) and every setting at its default; RULES <hex> sets the rule word from then on
# (100 the stabilisers, 200 the 8-frame average, 400 the glide, 800 the ticks; F00 all of them,
# the default build); SET <n>=<v>,... changes settings from then on;
#   FRAME [buttons=0x...] [lpad=x,y] [rpad=x,y] [s82=n] -> <reports>|- [<haptic events>]
